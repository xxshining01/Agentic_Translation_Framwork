# Prompt Engineering Invariants & Guardrails

## 1. Persistent Invariant Prompting (ส่งแกนคำสั่งทุกพร็อมพ์)
- **[RULE_PERSISTENT_INVARIANT]**: ในระบบที่ส่งคำสั่งแปลแบบ Multi-turn (เช่น ChatGPT Web Bridge หรือ API Conversation):
  1. ห้ามพึ่งพาความจำในอดีตของโมเดลเพียงอย่างเดียว (Attention Decay Prevention)
  2. ทุกๆ พร็อมพ์ที่ส่งไปประมวลผล (รวมถึง Follow-up Prompts #2, #3, #4...) จะต้องมี **Mini-System Invariant (กฎเหล็กประจำระบบ)** แนบไปด้วยเสมอ:
     - กฎการคงสภาพ Control Tags/XML Tags 100%
     - กฎความยาวบรรทัดและการตัดบรรทัดให้พอดีกับกล่องข้อความเกม (Natural In-cell Line Break ~40-48 ตัวอักษร)
     - กฎการแปลคำอุทาน/เสียงคราง/เสียงหายใจเหนื่อย (ห้ามแปล panting เป็น "ฮะ")
     - กฎการล็อกคำศัพท์และชื่อเฉพาะ 1:1

## 2. Explicit Speaker-Listener Pairing (ระบุคู่สนทนาให้ชัดเจน)
- **[RULE_EXPLICIT_PAIR_DYNAMIC]**: ในการสร้าง Prompt ส่งบทสนทนาให้ AI แปล:
  1. นอกจากส่งชื่อผู้พูด (`speaker`) แล้ว ระบบต้องพยายามระบุ **"ผู้ฟัง (target_listener)"** ให้ชัดเจนในบริบทของแต่ละฉาก
  2. เมื่อทราบทั้ง Speaker และ Listener ระบบต้องยัด **Pairwise Pronoun Rule** กำกับลงไปในพร็อมพ์ เช่น `[Dan -> Shion: Dan เรียกตัวเองว่า "ผม" เรียก Shion ว่า "คุณ" ลงท้าย "ครับ"]` เพื่อไม่ให้สรรพนามแกว่งไปมาระหว่าง นาย / เธอ / แก / คุณ

## 3. Speaker Forward-Propagation (ป้องกันประโยคตาบอด)
- **[RULE_SPEAKER_PROPAGATION]**: สำหรับข้อความในเกมที่ผู้พูดคนเดิมพูดต่อเนื่องหลายกล่อง/หลายบรรทัด:
  - หากบรรทัดถัดไปมี `speaker: ""` (ว่างเปล่า) แต่อยู่ใน Event หรือ Scene เดียวกัน ให้ทำการ **Forward-Fill (ส่งต่อชื่อผู้พูด)** จากบรรทัดก่อนหน้า
  - ป้องกันไม่ให้ `GlossaryScanner` สแกนไม่พบตัวละคร แล้วส่งผลให้ `profiles_context` ว่างเปล่าจน AI ต้องสุ่มเดาเพศและสรรพนามเอาเอง

## 4. Balanced Narrative Length (ความยาวและลีลาภาษาคงที่)
- **[RULE_BALANCED_NARRATIVE]**: สถาปัตยกรรมการสร้างพร็อมพ์ต้องกำกับลีลาภาษา (Literary Tone) ให้เสถียร:
  - ไม่แปลแบบตัดทอนคำเพียงเพื่อบีบให้กระชับสั้น
  - ไม่แปลแบบยืดยาวเยิ่นเย้อหรือขยายความเกินต้นฉบับ
  - ไม่ว่า Batch จะถูกแบ่งย่อย (Bisect) เหลือ 1 ประโยค หรือส่งไปเป็นชุด 15 ประโยค มาตรฐานความละเอียดและความยาวของคำแปลต้องสม่ำเสมอดุจนักแปลคนเดียวกัน

## 5. System Messages & UI Register Invariants (กฎกำกับข้อความระบบและหน้าต่างเกม)
- **[RULE_SYSTEM_UI_REGISTER]**: สำหรับข้อความที่เป็นคำสั่งระบบ, การแจ้งเตือนไอเทม, หน้าต่างเซฟ/โหลด, หรือระบบต่อสู้:
  1. **Zero-Pronoun Invariant:** ห้ามใส่สรรพนามบุคคล ("ฉัน", "ผม", "คุณ", "ท่าน", "พวกเรา") โดยเด็ดขาด
  2. **High Spatial Economy:** ใช้คำสั้น กระชับ กึ่งทางการ (Impersonal Declarative / Passive) ไม่ล้นขอบจอ HUD หรือกล่องแจ้งเตือน
  3. **Standard Lexicon Patterns:**
     - ได้รับ/สูญเสียไอเทม: `ได้รับ [ไอเทม] x1` (ห้ามแปล "คุณได้รับ...", "เก็บ...ได้แล้ว")
     - สถานะสิ่งกีดขวาง: `ประตูปิดล็อคอยู่`, `ไม่สามารถเปิดได้ในขณะนี้`, `กุญแจไม่ตรงกัน`
     - เซฟ/โหลด/ระบบ: `บันทึกข้อมูลเรียบร้อย`, `ต้องการออกจากเกมหรือไม่?`
     - การต่อสู้: `การโจมตีพลาดเป้า!`, `หลบหลีกสำเร็จ!`, `ได้รับค่าประสบการณ์ 100 EXP`

## 6. Omniscient Narrator & Inspection Register (กฎกำกับผู้บรรยายและข้อความสำรวจ)
- **[RULE_NARRATOR_REGISTER]**: สำหรับข้อความบรรยายเรื่องเล่ามุมมองบุคคลที่สาม หรือการสำรวจสิ่งแวดล้อมที่ไร้ Speaker Tag:
  1. **Literary Prose Register:** ใช้ภาษาเขียนเชิงวรรณศิลป์ สุขุม นุ่มลึก ถ่ายทอดภาพ อารมณ์ และบรรยากาศ (Sensory Imagery)
  2. **No Colloquial Speech Particles:** ปราศจากคำสร้อยหรือหางเสียงการพูด เช่น "นะ", "จ้ะ", "ล่ะ", "เหรอ", "สิ"
  3. **Objective Environmental Inspection:** การสำรวจวัตถุ (เช่น ตู้หนังสือ, ประตู, โต๊ะ) ให้บรรยายสภาพวัตถุอย่างเป็นกลาง เว้นแต่มีบริบทชัดเจนว่าเป็นการแสดงความคิดเห็นของตัวละครหลักที่ผู้เล่นกำลังควบคุมอยู่

## 7. Contextual SFX & Onomatopoeia Invariant (กฎกำกับการแปลเสียงเอฟเฟกต์และสัทพจน์ตามบริบท)
- **[RULE_CONTEXTUAL_SFX_CALIBRATION]**: การแปลเสียงธรรมชาติ, เสียงสรีระ (หายใจ/คราง/หอบ), และเสียงเอฟเฟกต์ (SFX/Onomatopoeia):
  1. **Strict Context Disambiguation:** ห้ามแปลคำเดียวกันเป็นคำเดิมเสมอไป ต้องปรับตามบริบทฉากอย่างเด็ดขาด:
     - `はぁ…`: หากเป็นฉากเหนื่อยใจ/ผิดหวัง -> "เฮ้อ...", หากเป็นฉากเหนื่อยหอบจากการวิ่ง/ต่อสู้ -> "แฮ่ก... แฮ่ก...", หากเป็นฉากเคลิ้ม/กระเส่า/บทรัก -> "ฮ่าห์... / อื้ม..."
     - `くっ…`: โดนโจมตี/บาดเจ็บ -> "อึ้ก...", สะกดอารมณ์เคียดแค้น -> "ชิ... / หนอย...", กลืนน้ำลายฝืดคอ -> "อึก..."
     - `ドカッ / バシッ`: หมัดชก/เตะ -> "ผัวะ! / พลั่ก!", ของหนักตกกระทบ -> "ตุ้บ! / โครม!"
     - `ピチャ / ビチャ`: น้ำกระเซ็น -> "ซ่า... / จ๋อม...", ของเหลวเปียกชุ่ม/เสียดสี -> "แจ๊ะ... / แฉะ..."
     - `ギクッ / ぎくっ / ビクッ`: สะดุ้งตกใจ/ผงะเมื่อถูกจับได้หรือชะงัก -> "สะดุ้ง...!", "ผงะ...!", "ชะงัก...!" (⚠️ ข้อห้ามเด็ดขาด: ห้ามแปลเป็นสำนวนดาษดื่น "สะดุ้งเฮือก" หรือทับศัพท์ "กึก" โดดๆ)
     - `ドキッ / ドキン`: หัวใจกระตุกวูบ/ใจเต้นไม่เป็นส่ำ -> "ใจกระตุก...!", "ตึกตัก...!", "วูบ...!"
  2. **Punctuation & Length Preservation:** คงเครื่องหมายยัติภังค์ (`...`), อัศเจรีย์ (`!`), หัวใจ (`♥`), และตัวลากเสียงตามต้นฉบับอย่างเคร่งครัด
  3. **No Direct Transliteration:** ห้ามถอดเสียงทับศัพท์ตรงตัว (เช่น ห้ามแปล `ドカッ` เป็น "โดกัต" หรือ `ピチャ` เป็น "ปิฉะ") ต้องใช้สัทพจน์ภาษาไทยมาตรฐานตามวรรณกรรมสากล
