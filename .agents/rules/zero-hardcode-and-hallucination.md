# Zero Hardcode & Zero Hallucination Directives

## 1. Zero Hardcode Directive (ห้ามเดาหรือคิดเอาเองโดยไร้หลักฐาน)
- **[RULE_ZERO_HARDCODE]**: ห้ามคาดเดาหรืออนุมานเอาเองจากชื่อตัวละครเพียงอย่างเดียวว่าต้องเป็นเพศใด (หญิง/ชาย/เพศทางเลือก) หรือมีบุคลิกอย่างไร (สุภาพ/ก้าวร้าว/นักเลง) โดยปราศจากหลักฐานเชิงประจักษ์ (Evidence-Based Reasoning):
  1. **ห้ามสร้าง "Default Trap":** ห้ามเขียนโค้ดที่ Fallback ตัวละครนิรนามหรือตัวละครที่ไม่ทราบเพศให้กลายเป็น "ชายสุภาพ (Default Polite Male: ผม/คุณ/ครับ)" โดยเด็ดขาด เพราะจะทำให้ตัวละครหญิงและนักเลงพูดผิดเพศและผิดบุคลิก
  2. **Evidence-Driven Profiling:** ข้อมูลตัวละครทั้งหมด (เพศ, อายุ, บุคลิก, สรรพนาม) ต้องมาจากการสกัดหลักฐาน (Dialogue Evidence Extraction), ข้อมูลจาก Game Database (System.json, Actors, Enemies), หรือการวิเคราะห์ความสัมพันธ์จริง (Pairwise Relationship Analysis)
  3. **Neutral Fallback When Uncertain:** หากข้อมูลไม่เพียงพอจริงๆ และไม่สามารถยืนยันเพศหรือสถานะได้ ระบบต้อง Fallback เป็นสรรพนามกลางที่ปลอดภัย (Neutral Speech Register เช่น "ฉัน / เธอ / นาย") และต้องไม่ยัดเยียดหางเสียง "ครับ" หรือ "ค่ะ" จนกว่าจะมีหลักฐานยืนยัน

## 2. Zero Hallucination Directive (ห้ามหลอน ห้ามคิดเอง)
- **[RULE_ZERO_HALLUCINATION]**: ห้ามสร้างข้อมูล แปลความหมายเกินจริง หรือแต่งเติมเนื้อหาที่ไม่มีอยู่จริงในต้นฉบับหรือไฟล์ฐานข้อมูล:
  1. **Strict Data Grounding:** ข้อมูลทุกอย่างที่นำมาสร้างเป็นพร็อมพ์ (Prompt Assembly) ต้องอ่านและตรวจสอบจากไฟล์จริงบนดิสก์ ห้ามสมมุติ Schema, ห้ามจำลองเนื้อหาไฟล์ และห้ามเดา Path
  2. **Code Truthfulness:** ห้ามเดาว่ามีคลาสหรือฟังก์ชันใดๆ อยู่ในระบบโดยไม่ได้เปิดดูโค้ดจริง ห้ามสมมุติว่า API มีพารามิเตอร์ที่ไม่มีอยู่จริง
  3. **Translation Fidelity:** ห้าม AI นักแปลตัดทอนเนื้อหาสำคัญ (Over-pruning) หรือแต่งเติมเนื้อหายืดยาวเกินต้นฉบับ (Over-expansion) เพียงเพราะขนาดของ Batch เปลี่ยนไป

## 3. Anti-Politeness Bias (กำจัดอคติความสุภาพของ LLM)
- **[RULE_ANTI_POLITE_BIAS]**: โมเดลภาษา (เช่น ChatGPT/GPT-4o) มีแนวโน้มโดยธรรมชาติที่จะแปลทุกอย่างให้สุภาพเกินจริง (Polite & Helpful Bias):
  - ตัวละครที่เป็นนักเลง, อันธพาล, ศัตรู, หรือคนในชนชั้นต่ำกว่า/เพื่อนสนิท ต้องได้รับการคุมโทนให้ตรงตามบทบาท (เช่น ฉัน/แก, ข้า/เอ็ง, กู/มึง ตามความเหมาะสมของเนื้อเรื่อง)
  - ห้ามปล่อยให้ AI เปลี่ยนคำพูดของนักเลงหรือบทข่มขู่กลายเป็น "ผม / คุณ / ครับ" เด็ดขาด

## 4. No Naive Parenthesis Bias (ห้ามยึดติดว่าวงเล็บคือคิดในใจของตัวเอก)
- **[RULE_NO_PARENTHESIS_BIAS]**:
  - **ห้ามเดาว่าข้อความที่มี `()` หรือ `（）` คือ "คิดในใจของพระเอก" เสมอไป:** วงเล็บในเกมญี่ปุ่นมีความหมายได้หลากหลายมิติ:
    1. การกระซิบ, พึมพำ, หรือสบถเบาๆ ของตัวละครใดๆ ในฉาก
    2. บันทึกคำอธิบายระบบ หรือคำแนะนำผู้เล่น (System Guidance / Gameplay Hint)
    3. ท่าทาง, การกระทำ, หรือสัทพจน์ (Action / Stage Direction / SFX)
    4. ความคิดในใจของตัวละครอื่นๆ (ไม่ใช่เฉพาะตัวเอก)
  - **Contextual Linguistic Disambiguation:** การกำหนดว่าข้อความนั้นใครเป็นผู้พูด (Speaker) หรือผู้ฟัง (Listener) ต้องวิเคราะห์จาก **"รูปประโยค เนื้อหา และบริบทของฉาก (Context & Linguistic Register)"** ว่าเป็นการสื่อสารกับผู้เล่น (System/Narrator) หรือพูดถึงตัวเองหรือตัวละครอื่น ห้ามยัดเยียด Default เป็นตัวเอกโดยไร้หลักฐานเด็ดขาด
