# Literary Style Calibration & Localization Craft Skill

คู่มือมาตรฐานศิลปะการแปลวรรณกรรมเกมภาษา (Japanese/English -> Thai Video Game Localization) เพื่อให้ได้งานแปลที่สละสลวย มีมิติทางอารมณ์ และกลมกลืนกับบริบทของเกม

---

## 1. Speech Registers & Character Personas (ระดับภาษาตามบทบาท)
งานแปลระดับพรีเมียมต้องไม่ใช้ "ภาษาทางการระดับเดียว" กับตัวละครทุกคน:

| ระดับภาษา (Register) | ตัวอย่างกลุ่มตัวละคร | สรรพนาม (ตัวเอง / คู่สนทนา) | คำลงท้าย / สำนวน |
| :--- | :--- | :--- | :--- |
| **High Formal / Noble** | ขุนนาง, ราชา, นักบวชชั้นสูง | ข้าพเจ้า / ท่าน, ฝ่าบาท | ขอรับ / เจ้าค่ะ / ครับท่าน |
| **Polite Formal** | คนรับใช้ผู้จงรักภักดี, อัศวิน | กระผม / คุณท่าน, นายท่าน | ขอรับ / เจ้าค่ะ / ครับผม |
| **Modern Polite** | สุภาพบุรุษ, นักวิชาการ, ตัวเอกทั่วไป | ผม, ฉัน / คุณ | ครับ, ค่ะ |
| **Intimate / Familiar** | เพื่อนสนิท, คนรัก, พี่น้อง | ฉัน / เธอ, พี่ / น้อง, เรา / แก | จ้ะ, นะ, สิ (ไร้ครับ/ค่ะ) |
| **Rough / Thuggish** | นักเลง, โจร, อันธพาล, ศัตรู | ข้า / เอ็ง, กู / มึง, ฉัน / แก | วะ, เว้ย, โว้ย (ห้ามใช้ครับ/ค่ะ) |
| **Innocent / Child** | เด็กเล็ก, สิ่งมีชีวิตตัวน้อย | หนู, ผม / พี่, คุณลุง, น้า | ค่ะ, ครับ, จ้ะ |

## 2. Context-Sensitive Onomatopoeia & SFX Matrix (เมทริกซ์สัทพจน์และเสียงเอฟเฟกต์ตามบริบท)
ห้ามแปลเสียงธรรมชาติแบบทับศัพท์แข็งๆ (ห้ามแปล `ドカッ` เป็น "โดกัต" หรือ `ピチャ` เป็น "ปิฉะ") และ **ห้ามแปลคำเดียวกันเป็นความหมายเดียวตลอดทั้งเกม** คำภาษาญี่ปุ่นคำเดียวกัน ความยาวเท่ากัน แต่ต่างบริบท (การต่อสู้ vs บทรัก vs ชีวิตประจำวัน) ต้องแปลแตกต่างกันอย่างสิ้นเชิง:

### 2.1 หมวดเสียงสรีระ การหายใจ และเสียงคราง (Physiological, Respiration & Moans)
| ต้นฉบับ (Japanese) | บริบทการใช้งาน (Dramatic Context) | ตัวอย่างคำแปลภาษาไทยมาตรฐาน | ข้อห้ามเด็ดขาด (Strict Invariants) |
| :--- | :--- | :--- | :--- |
| `はぁ… / ハァ…` | 1. **ถอนหายใจ** (เหนื่อยใจ / ผิดหวัง / โล่งอก) | **"เฮ้อ..."**, **"เฮ่อ..."** | ⚠️ ห้ามใช้ "แฮ่ก" หรือ "ฮ่าห์" ในฉากถอนหายใจ |
| | 2. **หอบเหนื่อย** (วิ่งหนี / หายใจไม่ทัน / สู้หนัก) | **"แฮ่ก... แฮ่ก..."**, **"ฮู่..."** | ⚠️ ห้ามแปลเป็น "ฮะๆ" เด็ดขาด (ฮะ เป็นหางเสียง ไม่ใช่เสียงหอบ) |
| | 3. **หายใจกระเส่า / เคลิ้ม** (บทรัก / ลมหายใจร้อน) | **"ฮ่าห์..."**, **"ฮึ่ม..."**, **"อื้ม..."** | ⚠️ ห้ามใช้ "เฮ้อ" ในฉากโรแมนติกหรืออีโรติก |
| `ふぅ… / フゥ…` | 1. **โล่งอก** หลังผ่านสถานการณ์คับขัน | **"ฟู่..."**, **"เฮ้อ..."** | ให้เลือกระหว่างการผ่อนคลายกับความโล่งใจ |
| | 2. **เป่าลม / เป่าของร้อน / พ่นควัน** | **"ฟู่..."** | |
| `くっ… / ぐっ…` | 1. **สะกดความเจ็บปวด** (โดนโจมตี / ฝืนทนบาดแผล) | **"อึ้ก..."**, **"กึก..."**, **"อึก..."** | ให้รสสัมผัสของการกัดฟันกลืนความเจ็บปวด |
| | 2. **สะกดอารมณ์เคียดแค้น / คับแค้นใจ** | **"ชิ..."**, **"หนอย..."**, **"บ้าเอ๊ย..."** | |
| | 3. **กลืนน้ำลายฝืดคอ / ตกตะลึง** | **"อึก..."** | |
| `んっ… / んぁ…` | 1. **สงสัย / ครุ่นคิดในลำคอ** | **"หืม..."**, **"อืม..."** | |
| | 2. **ดิ้นรน / ถูกปิดปาก / ขัดขืน** | **"อื้อ...!"**, **"อื้อออ!"** | เสียงอู้อี้ในลำคอ |
| | 3. **เสียงครางกระเส่า / วาบหวิว (Sensual Moans)** | **"อื้ม..."**, **"อ๊า..."**, **"ฮื่อ..."**, **"อื้อ..."** | คุมโทนวรรณศิลป์ ไม่ให้กระด้าง |
| `あっ… / あんっ…` | 1. **สะดุ้งตกใจเล็กน้อย / นึกขึ้นได้** | **"อ๊ะ..."**, **"เอ๊ะ..."** | |
| | 2. **เสียงครางหลุดปาก / เสียวซ่าน** | **"อ๊า..."**, **"อ๊าง..."**, **"อ๊ะ..."** | ตามระดับความรู้สึกของตัวละคร |
| `ひっ… / ひぃっ…` | **หวาดกลัวสุดขีด / กรีดร้องผวาภัย** | **"ฮี้...!"**, **"กรี๊ด...!"**, **"หวา...!"** | เสียงสั่นผวา |

### 2.2 หมวดการต่อสู้ แรงปะทะ และของแข็งกระทบ (Combat, Impact & Blunt Force)
| ต้นฉบับ (Japanese) | บริบทการใช้งาน (Dramatic Context) | ตัวอย่างคำแปลภาษาไทยมาตรฐาน |
| :--- | :--- | :--- |
| `ドカッ / バシッ / ボコッ` | หมัดชก / ส้นเท้าเตะกระแทกเนื้อ / การทำร้ายร่างกาย | **"ผัวะ!"**, **"พลั่ก!"**, **"ตุ้บ!"** |
| `バキッ / ボキッ / ゴスッ` | ของแข็งฟาด / กระดูกหัก / ทุบตีอย่างรุนแรง | **"กร๊อบ!"**, **"เปรี้ยง!"**, **"โป๊ก!"** |
| `ピシャッ / パチン` | ฝ่ามือตบหน้าอย่างจัง | **"เพียะ!"** |
| `ズシン / ドスン / ドサッ` | ร่างกายหรือของหนักร่วงกระแทกพื้น / ล้มคว่ำ | **"ตุ้บ!"**, **"โครม!"**, **"ตึง!"** |
| `ザシュッ / スパッ` | คมดาบฟันเฉือนเนื้อ / ของมีคมกรีดผ่าน | **"ฉัวะ!"**, **"ชิ้ง!"** |
| `シュッ / サッ / フッ` | การเคลื่อนไหวหลบหลีกรวดเร็ว / ฟาดอากาศ | **"ฟึ่บ!"**, **"วูบ!"** |

### 2.3 หมวดของเหลว น้ำไหล และความเปียกชื้น (Fluid, Liquid & Wet Sounds)
| ต้นฉบับ (Japanese) | บริบทการใช้งาน (Dramatic Context) | ตัวอย่างคำแปลภาษาไทยมาตรฐาน |
| :--- | :--- | :--- |
| `ピチャ / ビチャ / ビチャビチャ` | 1. น้ำกระเซ็น / เดินย่ำแอ่งน้ำขัง | **"ซ่า..."**, **"จ๋อม..."**, **"แฉะ..."** |
| | 2. ของเหลวเปียกชุ่ม / เนื้อกระทบของเหลว (Intimate) | **"แจ๊ะ..."**, **"แฉะ... แฉะ..."**, **"แฉะชุ่ม..."** |
| `グチュ / ニュル / ドロ` | ของเหลวหนืด / สไลม์ / โคลนดูด / การบดขยี้ | **"ยวบ..."**, **"แฉะ..."**, **"หนืด..."** |
| `ザー / ザーザー` | ฝนตกหนัก / น้ำตก / คลื่นซัดฝั่ง | **"ซ่า..."**, **"ซ่าๆ..."** |
| `ポタポタ / ピチャン` | หยดน้ำร่วงกระทบผิวน้ำหรือพื้น | **"ติ๋ง..."**, **"แปะ... แปะ..."** |

### 2.4 หมวดกลไก วัตถุ และสิ่งแวดล้อม (Mechanical, Environmental & Psychological)
| ต้นฉบับ (Japanese) | บริบทการใช้งาน (Dramatic Context) | ตัวอย่างคำแปลภาษาไทยมาตรฐาน |
| :--- | :--- | :--- |
| `ガチャ / カチャ` | บิดลูกบิดประตู / ปลดล็อคกุญแจ / ชักกระบอกปืน | **"แกร๊ก"**, **"คลิก"** |
| `バタン / ガン` | ประตูปิดกระแทกอย่างแรง / ทุบโต๊ะเสียงดัง | **"ปัง!"**, **"โครม!"** |
| `ギィ… / ギー` | ประตูไม้เก่าหรือบานพับเปิดดังเอี๊ยดอ๊าด | **"เอี๊ยด..."**, **"เอี๊ยดด..."** |
| `ゴゴゴ… / ズズズ…` | แผ่นดินสะเทือน / ประตูกลเลื่อน / บรรยากาศกดดันมืดมน | **"ครืน..."**, **"ครืนๆ..."** |
| `ドキドキ / ドクン` | เสียงหัวใจเต้นระทึก (ตื่นเต้น / หวาดกลัว / ตกหลุมรัก) | **"ตึกตัก... ตึกตัก..."**, **"ตึก... ตัก..."**, **"ตุบ... ตุบ..."** |
| `ゾクッ / ゾクゾク` | อาการขนลุกซู่ / เสียวสันหลังวาบ (สยองขวัญ หรือสุขสม) | **"วูบ..."**, **"เสียววาบ..."**, **"เย็นวาบ..."** |
| `プルプル / ガタガタ` | ตัวสั่นงันงก (หวาดกลัวจัด / หนาวสะท้าน) | **"สั่นริกๆ..."**, **"กึกๆ..."** |

### 2.5 กฎเหล็กด้านวรรณศิลป์และจังหวะของสัทพจน์ (Stylistic Invariants)
1. **Punctuation & Length Preservation:** เครื่องหมายยัติภังค์ (`...` / `…`), อัศเจรีย์ (`!`), หัวใจ (`♥`), และตัวลากเสียง (`ー`, `～`) ต้องคงอารมณ์ความยาวของเสียงไว้ เช่น `あっ……！` -> `"อ๊ะ......!"`, `はぁぁ…` -> `"ฮ่าห์..."`
2. **Stuttering & Syllable Repetition:** การพูดติดอ่างหรือตะกุกตะกัก
   - หากเป็นชื่อเฉพาะภาษาอังกฤษ (เช่น `D-Dan...!`, `S-Shion...?`): ให้คงอักษรภาษาอังกฤษตัวหน้าไว้ (เช่น `D-Dan...!`, `S-Shion...?`) ห้ามผสมพยัญชนะไทยกับชื่ออังกฤษ (ห้ามเขียน `ด-Dan`)
   - หากเป็นคำไทย ให้ซ้ำพยัญชนะไทยตามธรรมชาติ เช่น `ม-ไม่ใช่`, `อ-อย่า`

## 3. Game UI Box Formatting & Natural Line Breaks (การคุมความยาวบรรทัด)
- หน้าต่างข้อความของเกม RPG และ Visual Novel ส่วนใหญ่ **ไม่มีระบบ Auto-wrap** ข้อความที่ยาวเกิน 40-48 ตัวอักษรจะล้นขอบจอและตกหล่น
- **SOP การตัดบรรทัด (In-Cell Line Break `\n`):**
  1. หากอนุประโยคหรือข้อความยาวเกิน ~40-48 ตัวอักษร ให้ตัดขึ้นบรรทัดใหม่ด้วย `\n` ทันที
  2. ต้องตัดที่ **"รอยต่อทางไวยากรณ์หรือจังหวะหายใจที่กลมกลืน"** เช่น หลังเครื่องหมายวรรคตอน, หลังคำเชื่อม (และ, แต่, เพราะ), หรือหน้ากริยาหลัก
  3. ห้ามตัดกลางคำศัพท์หรือชื่อเฉพาะ (เช่น ห้ามตัด `ดาบแห่ง\\nแสง`, ห้ามตัด `คุณ\\nชิออน`)
  4. แท็กควบคุมท้ายบรรทัด (`\.`, `\!`, `\^`) ต้องอยู่ชิดท้ายบรรทัดก่อน `\n` เสมอ

## 4. System Messages, UI Alerts & Omniscient Narrator Standards

### 4.1 System Messages & Engine HUD (ข้อความระบบและการแจ้งเตือน)
- **วัตถุประสงค์:** สื่อสารสถานะ กลไกเกม หรือผลลัพธ์ของการกระทำอย่างรวดเร็ว ชัดเจน ปราศจากความสับสน
- **กฎเหล็ก (Zero Pronouns):** ห้ามใช้สรรพนามบุคคล ("ฉัน", "ผม", "คุณ", "ท่าน", "เรา") เด็ดขาด
- **พจนานุกรมสำนวนระบบมาตรฐาน:**
  - `ได้รับ [ไอเทม] x1` / `สูญเสีย [ไอเทม] x1`
  - `ประตูปิดล็อคอยู่` / `กลไกถูกเปิดใช้งานแล้ว` / `ต้องการบันทึกข้อมูลหรือไม่?`
  - `การโจมตีพลาดเป้า!` / `หลบหลีกสำเร็จ!` / `พ่ายแพ้การต่อสู้...`

### 4.2 Omniscient Narrator & Stage Atmosphere (ผู้บรรยายฉาก)
- **วัตถุประสงค์:** สร้างภาพและอารมณ์ร่วมให้แก่ผู้เล่นผ่านถ้อยคำวรรณศิลป์
- **ระดับภาษา:** ภาษาเขียนเชิงพรรณนา (Literary Prose) สุขุม นุ่มลึก ไม่ใช้คำสแลง และไม่มีหางเสียงการพูด (เช่น ไม่ใช้ "ล่ะ", "จ้ะ", "นะ")
- **ตัวอย่าง:**
  - `สายฝนโปรยปรายลงมาอย่างไม่ขาดสาย ท่ามกลางความเงียบงันของป่าลึก`
  - `ความมืดมิดเข้าปกคลุมทั่วทั้งโถงทางเดิน มีเพียงกลิ่นอับชื้นที่ลอยมาแตะจมูก`

### 4.3 Environmental Inspection Texts (การสำรวจสิ่งแวดล้อม)
- ข้อความตรวจสอบวัตถุ (โต๊ะ, ตู้, ประตู, ร่องรอย) ให้เน้นบรรยายสภาพทางกายภาพอย่างเป็นกลาง
- หากเป็นข้อความแสดงความรู้สึก ให้ยึดโยงกับตัวละครที่ผู้เล่นกำลังควบคุมอยู่ ณ ขณะนั้น (Party Leader)
