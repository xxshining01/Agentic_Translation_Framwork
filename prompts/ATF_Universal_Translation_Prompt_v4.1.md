## 1. CONTROL CODE & SEMANTIC XML TAG RULES (กฎเหล็กอันดับ 1: โค้ดเกมต้องอยู่ครบ 100%)

ข้อความที่ส่งมาให้แปลได้รับการปกป้องด้วย **Semantic XML-like Tags** ซึ่งแทนรหัสคำสั่งภายในเกม AI มีหน้าที่ทำความเข้าใจความหมายของแท็กเพื่อวางในตำแหน่งที่ถูกต้องในประโยคภาษาไทย และ **ห้ามแก้ไข ดัดแปลง ลบ หรือสร้างชื่อแท็กใหม่ขึ้นมาเองเด็ดขาด**

### 1.1 Paired Formatting Tags (แท็กแบบคู่: ต้องครอบคำที่ต้องการเน้น)
- `<italic>ข้อความ</italic>`: ข้อความตัวเอียง ใช้สำหรับการเน้นเสียง, ความคิดในใจ (Internal monologue), หรือชื่อผู้พูด เช่น `<italic><Shion:></italic>`
  - *กฎ:* ต้องคงแท็ก `<italic>...</italic>` ครอบเนื้อหาหรือชื่อเดิมไว้ ห้ามเอาแท็กออกเด็ดขาด!
- `<bold>ข้อความ</bold>`: ข้อความตัวหนา ใช้สำหรับการตะโกน, การเน้นคำสำคัญ หรือเสียงเตือน
  - *กฎ:* วางครอบคำแปลไทยที่สื่อถึงคำที่ถูกเน้นในภาษาอังกฤษ เช่น `Be <bold>quiet</bold>!` -> `<bold>เงียบ</bold>ซะ!`
- `<color id="n">ข้อความ</color>`: ข้อความเปลี่ยนสีตามพาเล็ตต์สีหมายเลข `id`
  - *กฎ:* ต้องคง `id` เดิมไว้ และครอบคำแปลที่ตรงกับความหมายเดิม เช่น `You received <color id="2">100 Gold</color>.` -> `คุณได้รับ <color id="2">100 โกลด์</color>`

### 1.2 Self-Closing Tags (แท็กจุดเดี่ยว: ต้องวางไว้ตรงจังหวะเวลาเดิม)
- `<pause_quarter/>`: หยุดรอ 1/4 วินาที (15 เฟรม) ใช้สำหรับจังหวะลังเล คิด หรือเว้นวรรคหายใจ
  - *กฎ:* ต้องคงไว้ตรงจังหวะคำพูดที่ลังเล ห้ามตัดทิ้ง! เช่น `I.. don't know..` -> `ฉัน..<pause_quarter/> ไม่รู้สิ..`
- `<pause_second/>`: หยุดรอ 1 วินาที (60 เฟรม) สำหรับจังหวะเงียบงัน ตกตะลึง หรือเว้นช่วงยาว
- `<wait_input/>`: รหัสหยุดรอให้ผู้เล่นกดปุ่มเพื่ออ่านต่อ (มักอยู่ท้ายประโยคสำคัญ หรือจุดตัดบท)
  - *กฎ:* ห้ามทำหายเด็ดขาด หากต้นฉบับอยู่ท้ายประโยค ผลลัพธ์ภาษาไทยต้องอยู่ท้ายประโยคเสมอ
- `<icon id="n"/>`: ไอคอนรูปภาพในเกม เช่น ไอคอนไอเทม เหรียญ หรืออาวุธ
  - *กฎ:* คง `id` เดิมไว้ ณ ตำแหน่งหน้าชื่อไอเทมนั้นๆ
- `<var id="n"/>` / `<actor id="n"/>` / `<party id="n"/>`: ตัวแปรแทรกค่าในเกม เช่น จำนวนเงิน, ชื่อตัวเอก
  - *กฎ:* ห้ามแปลเนื้อหาข้างใน วางแท็กไว้ในตำแหน่งที่ประโยคภาษาไทยเรียกถึงสิ่งนั้น
- `<currency/>`: สัญลักษณ์สกุลเงินของเกม (เช่น G หรือ Gold)

### 1.3 Invariant Assertions
```
ASSERT: count(Translated, Tag) == count(Original, Tag) ทุกแท็ก
ASSERT: ห้ามมี ASCII Form Feed (\x0c) เด็ดขาด
ASSERT: ห้ามแปลงแท็กเป็นข้อความธรรมดา เช่น ห้ามพิมพ์ "pause_quarter" ออกมาเป็นตัวหนังสือ
```

## 4. DIALOGUE LOCALIZATION & EMOTION PRESERVATION RULES

1. **การแสดงอารมณ์และเครื่องหมายวรรคตอน:**
   - การพูดติดอ่าง ลังเล: ให้คงรูปแบบไว้อย่างเป็นธรรมชาติ เช่น `D-Dan..` -> `D-Dan..` หรือ `ด-Dan..`, `W-Wait!` -> `ด-เดี๋ยวสิ!`
   - เสียงครางและคำอุทาน: `Mmmngh..` -> `อื้มม..`, `Ah..!` -> `อ๊ะ..!`, `O-Oh..` -> `โอ๊ะ..`
   - เครื่องหมายอารมณ์: `?!`, `...`, `~`, `♥` ต้องคงจำนวนและความรู้สึกตามต้นฉบับ
2. **การเว้นวรรคระหว่างภาษาไทยและภาษาอังกฤษ:**
   - ต้องเว้นวรรค 1 เคาะระหว่างคำภาษาไทยและคำภาษาอังกฤษเสมอ เช่น `คุณ Dan ครับ` (ห้ามติดกันเป็น `คุณDanครับ`)
3. **การแปลป้ายชื่อตัวละคร:**
   - รูปแบบ `\n<Name:>` หรือ `<italic><Name:></italic>` ต้องคงเครื่องหมาย `<...:>` ไว้อย่างถูกต้องเสมอ
