# 1. Purpose

TLAS Core Taxonomy เป็นมาตรฐานกลางสำหรับการอธิบายลักษณะของตัวละคร บทสนทนา และปัจจัยทางภาษาที่เกี่ยวข้องกับการแปล

Taxonomy นี้ถูกออกแบบเพื่อให้

* AI วิเคราะห์ Character Profile
* AI วิเคราะห์ Dialogue Metadata
* AI ตัดสินใจเลือกสรรพนาม
* AI ตัดสินใจเลือกระดับภาษา
* AI ตัดสินใจเลือก Honorific
* AI ตัดสินใจเลือก Vocabulary
* AI ตัดสินใจเลือก Sentence Style

โดยไม่ผูกติดกับภาษาใดภาษาหนึ่ง

# 3. Taxonomy Category

ระบบแบ่งออกเป็น 16 หมวดหลัก

| Code | Category     | Scope                |
| ---- | ------------ | -------------------- |
| GND  | Gender       | Character            |
| AGE  | Age Group    | Character            |
| SPC  | Species      | Character            |
| OCC  | Occupation   | Character            |
| STR  | Story Role   | Character            |
| PER  | Personality  | Character            |
| VAL  | Core Values  | Character            |
| BEL  | Beliefs      | Character            |
| REL  | Relationship | Character / Dialogue |
| EMO  | Emotion      | Dialogue             |
| SIT  | Situation    | Dialogue             |
| CTX  | Context      | Dialogue             |
| INT  | Intent       | Dialogue             |
| TON  | Tone         | Dialogue             |
| REG  | Register     | Output               |
| SPR  | Speech Habit | Character            |

# 4. Category Classification

ทุก Category ต้องระบุคุณสมบัติ

| Property | Description           |
| -------- | --------------------- |
| Static   | เปลี่ยนยาก            |
| Timeline | เปลี่ยนตามเนื้อเรื่อง |
| Dynamic  | เปลี่ยนทุก Dialogue   |

ตัวอย่าง

| Category     | Type     |
| ------------ | -------- |
| Gender       | Static   |
| Personality  | Timeline |
| Relationship | Timeline |
| Emotion      | Dynamic  |
| Tone         | Dynamic  |
| Register     | Dynamic  |

# 15. Language Independence

ID

ต้องไม่อ้างอิงภาษา

เช่น

❌

```text
PER_ผม
```

❌

```text
PER_BOKU
```

✅

```text
PER_FIRST_PERSON_MASCULINE_FORMAL
```

หรือถ้ายังไม่ลงถึงระดับนี้

```text
PRN_FIRST_MASC_FORMAL
```

แล้วค่อยให้ Mapping Layer แปลงเป็น

* ผม
* 僕
* I

ตามภาษาเป้าหมาย

---

# 16. Core Principle

Taxonomy มีหน้าที่เพียง

> **นิยาม "ความหมาย" ของคุณลักษณะทางภาษาและบริบท**

ไม่ใช่

* เก็บข้อมูลตัวละคร
* เก็บข้อมูล Dialogue
* เก็บผลลัพธ์การแปล

Taxonomy คือ **Vocabulary มาตรฐาน** ที่ทุกส่วนของ TLAS ใช้อ้างอิงร่วมกัน
