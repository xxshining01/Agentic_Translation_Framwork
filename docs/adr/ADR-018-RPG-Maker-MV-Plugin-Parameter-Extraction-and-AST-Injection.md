# ADR-018: RPG Maker MV Plugin Parameter Extraction and Safe AST/JSON Injection Architecture

## Status
Approved

## Context
ในกระบวนการแปลเกมภาษาที่พัฒนาด้วยเอนจิน RPG Maker MV/MZ กระบวนการดั้งเดิมจะมุ่งเน้นเฉพาะการสกัดข้อความจากฐานข้อมูลหลักในโฟลเดอร์ `data/*.json` (เช่น `Actors.json`, `Items.json`, `Skills.json`, `CommonEvents.json`, `MapXXX.json`) ซึ่งสามารถสกัดบทสนทนา (Dialogue) และเนื้อเรื่องหลักได้ครบถ้วน

อย่างไรก็ตาม เมื่อนำเกมที่แปลแล้วไปทดสอบเล่นจริง (In-Game Quality Assurance) พบว่า **ยังมีข้อความภาษาอังกฤษจำนวนมากปรากฏอยู่บนหน้าจอเกม** ในส่วนของ:
1. **ระบบเควสต์ (Quest Journal):** ชื่อหมวดหมู่เควสต์ (`Main Quests`, `Side Quests`), สถานะเควสต์ (`Available`, `Completed`, `Failed`), และปุ่มควบคุม (`Read Quest`, `Close`) จากปลั๊กอิน `YEP_QuestJournal`
2. **ระบบเวลาและปฏิทิน (Game Time System):** ช่วงเวลา (`Morning`, `Day`, `Evening`, `Night`), วันในสัปดาห์ (`Monday` - `Sunday`), เดือน (`January` - `December`) จากปลั๊กอิน `DK_Game_Time`
3. **ระบบเมนูและตัวเลือก (Option Windows):** ตัวเลือกปรับขนาดหน้าจอ (`Fullscreen`), ปุ่มซ่อนหน้าต่างข้อความ (`HideWindow`), และปุ่มลัดต่างๆ
4. **ระบบมินิเกม (Mini-Games UI):** ข้อความคำสั่งเบ็ดตกปลา, เหยื่อตกปลา, และข้อความแนะนำวิธีเล่น จากปลั๊กอิน `PKD_SimpleFishing`

ข้อความเหล่านี้ไม่ได้ถูกเก็บอยู่ใน `data/*.json` แต่อย่างใด หากแต่ถูกฮาร์ดโค้ดหรือกำหนดค่าไว้ภายในอ็อบเจกต์การตั้งค่าของปลั๊กอินในไฟล์ **`www/js/plugins.js`**

### 1. การวิเคราะห์สาเหตุเชิงลึกและความท้าทายทางวิศวกรรม (Engineering Challenges & RCA)

จากการตรวจสอบโครงสร้างไฟล์ `www/js/plugins.js` ในโปรเจกต์ (`Example RPGM Game/www/js/plugins.js` ขนาด 152,199 ไบต์) พบความซับซ้อนเชิงเทคนิค 4 ประการ:

#### RCA-1: Deeply Nested & Escaped JSON Strings (โครงสร้าง JSON ซ้อนทับหลายชั้น)
- ใน RPG Maker MV สถาปัตยกรรมตัวจัดการปลั๊กอิน (`PluginManager`) บังคับให้พารามิเตอร์ทุกตัวใน `$plugins[i].parameters` มีค่าเป็นสตริง (`string`) เท่านั้น
- ผู้พัฒนาปลั๊กอินชั้นนำ (เช่น Yanfly Engine, DK Plugins, Pheonix KageDesu) จึงต้องใช้วิธี Serialize โครงสร้างข้อมูลที่ซับซ้อน (Structs, Arrays, Dictionaries) ให้อยู่ในรูป **JSON String ที่ซ้อนอยู่ข้างในสตริงอีกชั้นหนึ่ง (Nested Stringified JSON)**
- **ตัวอย่างจริงในโปรเจกต์ (`YEP_QuestJournal`):**
  ```json
  "Quest Category Window": "{\"---Categories---\":\"\",\"Category Order\":\"[\\\"available\\\",\\\"completed\\\",\\\"failed\\\",\\\"all\\\"]\",\"Available Text\":\"\\\\i[192]Available (%1)\",\"Completed Text\":\"\\\\i[191]Completed (%1)\",\"Cancel Text\":\"\\\\i[161]Close\"}"
  ```
  บางปลั๊กอินมีการซ้อนกันลึกถึง 4 ชั้น (Escape Slashes: `\\\\\\\\\\\\\\\"`) การใช้ Regex ค้นหาและแทนที่แบบทื่อๆ (Naive Text Replacement) จะทำให้ Escape Sequence ผิดเพี้ยน และส่งผลให้ JavaScript พังทันทีที่โหลดเกม (`SyntaxError: Unexpected token in JSON`)

#### RCA-2: Code-and-Data Mixing Hazard (ความเสี่ยงแปลโดนโค้ดและสูตรคำนวณ)
- ใน `parameters` ของปลั๊กอิน มีทั้ง:
  - **ข้อความสำหรับแสดงผลให้มนุษย์อ่าน (Displayable Text):** เช่น `"Available (%1)"`, `"Fullscreen"`, `"Morning"`
  - **สูตรคำนวณ JavaScript (Formulas):** เช่น `"(Graphics.width / scale) - Graphics.width"`, `"Window_Base.prototype.lineHeight.apply(this, arguments)"`
  - **ตัวแปรและสวิตช์ของเกม (Game IDs):** เช่น `"baitVariableId:i": "22"`, `"onPlayerCatchFish:i": "22"`
  - **ชื่อไฟล์ทรัพยากร (Asset Names):** เช่น `"7RK"`, `"rod1"`, `"progressBarFill"`
  - **ค่าสีและคอนฟิก (CSS / Hex):** เช่น `"#ad189a"`, `"#CCCCCC"`, `"1280"`
- หากระบบถอดข้อความอย่างสุ่มสี่สุ่มห้าแล้วนำไปแปล ตัวแปรหรือสูตรคำนวณจะถูกโมเดลภาษาแปลเป็นภาษาไทย ส่งผลให้ตัวเกมแครช (Game Crash / Black Screen) ทันทีที่เปิดเกม

#### RCA-3: JavaScript File AST / Wrapper Boundary
- ไฟล์ `plugins.js` ไม่ใช่ไฟล์ JSON บริสุทธิ์ แต่เป็นไฟล์สคริปต์ JavaScript:
  ```javascript
  // Generated by RPG Maker.
  // Do not edit this file directly.
  var $plugins =
  [
    {"name":"Community_Basic", ...},
    ...
  ];
  ```
- การอ่านและเขียนกลับจำเป็นต้องแยก Wrapper (`var $plugins =\n` และ `;\n`) ออกจากตัวข้อมูล Array อย่างแม่นยำ 100%

#### RCA-4: Absence of Traceability & Bi-directional Parity
- ที่ผ่านมา ATF ยังไม่มีเครื่องมือที่แปลงข้อความจาก `plugins.js` เข้าสู่มาตรฐาน CSV ของ TLAS (`Original, Initial, Filename, Row, Note, Role, Speaker, Displayable`) ทำให้ผู้แปลไม่สามารถตรวจสอบ, แปล, หรือบันทึก Checkpoint ของข้อความส่วนปลั๊กอินได้เหมือนข้อความในเกมทั่วไป

## Decision

เราตัดสินใจสร้างสถาปัตยกรรม **RPG Maker MV Plugin Parameter Extraction and Safe AST/JSON Injection Framework** บรรจุลงในไปป์ไลน์เสริม **Plugin Localization Engine (Stage 7)** โดยมีหลักการเชิงวิศวกรรม 5 ประการ:

### 1. Recursive JSON Unpacker & Pack-Back Architecture (การถอดและประกอบแบบทวนซ้ำ)
- ออกแบบอัลกอริทึม **Recursive Stringified JSON Traversal**:
  - เมื่อพบค่าใน `parameters` ที่ขึ้นต้นด้วย `{"` หรือ `["` ให้ทำการ `json.loads()` แบบทวนซ้ำ (Recursively) จนกระทั่งถึง Primitive Values (String, Number, Boolean)
  - สร้างแผนที่ที่อยู่ (JSON Path Expression) กำกับทุกตำแหน่ง เช่น:
    `YEP_QuestJournal.parameters['Quest Category Window']['Available Text']`
  - ในขั้นตอน Injection ให้ประกอบกลับจากชั้นในสุดออกมาสู่ชั้นนอกสุด โดยใช้ `json.dumps()` เพื่อให้ Escape Sequence (`\"`, `\\\"`, `\\\\\\\"`) ถูกสร้างขึ้นอย่างถูกต้องตามไวยากรณ์ของภาษา JavaScript โดยอัตโนมัติ

### 2. Strict Semantic Classification & Whitelist/Blacklist Filtering
สร้างระบบจำแนกประเภทข้อมูล (Semantic Classifier) เพื่อคัดกรองเฉพาะข้อความที่มนุษย์อ่านได้:
- **Blacklist Attributes (ห้ามสกัด/ห้ามแปลเด็ดขาด):**
  - คีย์ที่มีคำบ่งชี้ชนิดข้อมูล: `:bool`, `:css`, `:color`, `:file`, `:img`, `:image`, `:variable`, `:switch`, `:id`, `:i`, `:e`
  - คีย์ระบบ: `name`, `status`, `description`, `folder`, `filename`, `skin`, `fontFace`, `formula`
  - ข้อความที่มีไวยากรณ์ JavaScript: มีวงเล็บฟังก์ชัน `()`, การเข้าถึงเมธอด `.prototype.`, เครื่องหมายคำนวณ `Graphics.`
  - ข้อความที่เป็นตัวเลขเพียวๆ, รหัสสี Hex (`#ffffff`), หรือ Boolean (`true`/`false`)
- **Whitelist Attributes (อนุญาตให้สกัดและแปล):**
  - คีย์ที่ลงท้ายหรือมีคำว่า: `Text`, `Title`, `Name`, `Command`, `Format`, `Label`, `Message`, `Prompt`
  - ข้อความที่มีตัวอักขระภาษาธรรมชาติ และมีรูปแบบการจัดวางข้อความของ RPG Maker เช่น `\i[192]Available (%1)`

### 3. Unified ATF CSV Interoperability (การเชื่อมโยงกับ CSV มาตรฐาน)
- สกัดข้อความที่ผ่านการคัดกรองลงสู่ไฟล์ CSV ที่มี Schema มาตรฐาน 8 คอลัมน์ของ ATF:
  - `Original`: ข้อความภาษาอังกฤษต้นฉบับ เช่น `\i[192]Available (%1)`
  - `Initial`: ข้อความภาษาไทย (ดึงจาก Checkpoint หรือเว้นว่างเพื่อแปล)
  - `Filename`: `plugins.js`
  - `Row`: ลำดับของรายการข้อความ
  - `Note`: JSON Path ระบุตำแหน่งอ้างอิง เช่น `YEP_QuestJournal.parameters.Quest Category Window.Available Text`
  - `Role`: `UI/Plugin`
  - `Speaker`: ชื่อปลั๊กอิน เช่น `YEP_QuestJournal`
  - `Displayable`: `Yes`
- ทำให้ข้อความส่วนปลั๊กอินสามารถไหลเข้าสู่ Stage 4 (Translation Runtime), Stage 5 (Typography Parity), และ Stage 6 (Checkpoint Sync) ได้โดยตรงอย่างไร้รอยต่อ

### 4. Safe AST Extraction & Atomic File Replacement
- แยกและประกอบ JavaScript Wrapper อย่างปลอดภัย:
  ```python
  # Safe Parsing Boundary
  match = re.search(r"var\s+\$plugins\s*=\s*(\[[\s\S]*\])\s*;?", content)
  raw_json = match.group(1)
  plugins_data = json.loads(raw_json)
  ```
- เมื่อทำการ Inject คำแปลภาษาไทยกลับสู่ `plugins.js`:
  1. สร้างไฟล์สำรอง Timestamped Backup เสมอ (`plugins.js.backup_YYYYMMDD_HHMMSS.js`)
  2. เขียนไฟล์ลง `plugins.js.tmp`
  3. สลับไฟล์ด้วย `os.replace` ซึ่งเป็น Atomic Operation

### 5. Deterministic Format Code Preservation (`%1`, `\i[n]`, `\c[n]`)
- คุ้มครองรหัสควบคุมเอนจิน RPG Maker เช่น `\i[192]` (Icon), `\c[6]` (Color), และพารามิเตอร์การจัดวาง `%1`, `%2` ห้ามหลุดหายหรือบิดเบือน เพื่อให้ระบบ UI แสดงผลได้สมบูรณ์แบบ

## Consequences

### Positive
- **100% Comprehensive Game Localization:** ขจัดปัญหาข้อความ UI/Quest/Options หลุดแปลอย่างถาวร ทำให้ตัวเกมกลายเป็นภาษาไทยอย่างสมบูรณ์แบบทั้งระบบ
- **Zero Crash Guarantee:** การใช้ Recursive JSON Unpacker/Packer และ Semantic Classifier ช่วยการันตีว่าสูตรคำนวณและ Escape Sequences ใน `plugins.js` จะไม่เสียหาย 100%
- **Seamless Pipeline Integration:** สามารถใช้เครื่องมือแปล, ระบบ Checkpoint, และระบบจัดบรรทัดของ ATF กับข้อความปลั๊กอินได้ทันทีโดยไม่ต้องสร้างไปป์ไลน์แปลแยกใหม่
- **Safe Rollback:** มี Timestamped Backup ทุกครั้ง ป้องกันข้อผิดพลาดจากการดัดแปลงไฟล์เกม

### Negative / Trade-offs
- **Plugin Dependency Overhead:** ปลั๊กอินบางตัวเขียนโค้ดแหวกแนว (Custom serialization format ที่ไม่ใช่ JSON) ซึ่งอาจต้องเพิ่ม Custom Parser เฉพาะปลั๊กอินนั้นๆ ในอนาคต
