# SDD-001: Core Data Models and Event Payload Schema

**Project:** Agentic Translation Framework (ATF)
**Phase:** 3 - Software Design Document
**Status:** Draft

---

## 1. Overview

เอกสารนี้กำหนดโครงสร้างข้อมูลหลัก (Data Structure) ที่ใช้ในการส่งผ่านข้อมูลระหว่าง Agent และ Module ต่างๆ ผ่าน Event Bus ข้อมูลทั้งหมดจะถูกจัดการและตรวจสอบความถูกต้อง (Data Validation) อย่างเข้มงวดด้วย `Pydantic` ใน Python

## 2. Enums (สถานะของระบบ)

กำหนดสถานะทั้งหมดที่เป็นไปได้ของประโยค เพื่อใช้ควบคุม State Machine (อิงจาก SAD-002)

```python
from enum import Enum

class TokenState(str, Enum):
    UNPROCESSED = "UNPROCESSED"
    PENDING = "PENDING"
    TRANSLATING = "TRANSLATING"
    EDITING = "EDITING"
    QA_VERIFYING = "QA_VERIFYING"
    QA_FAILED = "QA_FAILED"
    TIMING = "TIMING"
    VALIDATING = "VALIDATING"
    READY_TO_EXPORT = "READY_TO_EXPORT"
    EXPORTED = "EXPORTED"
    ERROR_CRITICAL = "ERROR_CRITICAL"
    ALREADY_TRANSLATED = "ALREADY_TRANSLATED"

```

## 3. Sub-Models (โมดูลข้อมูลย่อย)

ข้อมูลบริบทและผลลัพธ์การแปลจะถูกแยกเป็น Sub-models เพื่อความเป็นระเบียบ

```python
from pydantic import BaseModel, Field
from typing import List, Optional, Dict

class ContextData(BaseModel):
    """ข้อมูลบริบทที่ Python ประกอบให้ AI (อิงจาก ADR-007)"""
    character_traits: List[str] = Field(default_factory=list, description="ลักษณะนิสัยของตัวละครที่กำลังพูด")
    glossary_matches: Dict[str, str] = Field(default_factory=dict, description="คำศัพท์ที่พบในประโยคและคำแปลบังคับ")
    translation_memory: List[Dict[str, str]] = Field(default_factory=list, description="ประโยคอ้างอิงที่เคยแปลและบริบทใกล้เคียง")
    story_summary: Optional[str] = Field(None, description="สรุปเหตุการณ์ของบทปัจจุบัน")
    style_rules: str = Field(default="", description="กฎเรื่องสไตล์จาก Master Prompt")
    symbol_engine_rules: str = Field(default="", description="กฎเรื่องสัญลักษณ์จาก Master Prompt")

class AgentOutputs(BaseModel):
    """ผลลัพธ์ที่ Agent แต่ละตัวจะนำมาเติมในช่องของตัวเอง"""
    translator_output: Optional[str] = None
    editor_output: Optional[str] = None
    qa_feedback: Optional[str] = Field(None, description="เหตุผลที่ QA สั่งตีกลับ (ถ้ามี)")
    timing_output: Optional[str] = None
    final_output: Optional[str] = None

```

## 4. Main Payload Schema (โครงสร้างหลัก)

`TranslationToken` คือ Object หลักที่จะไหลไปตาม Pipeline หากมีแท็กคำสั่งภาพหรือสคริปต์เอนจินเกม (เช่น โค้ดของ Ren'Py) มันจะถูกกรองและเก็บแยกไว้ใน `metadata` ก่อน เพื่อให้ `original_text` มีเฉพาะข้อความที่ต้องการแปลจริงๆ

```python
class TranslationToken(BaseModel):
    id: str = Field(..., description="ID อ้างอิงประโยคจากไฟล์ต้นฉบับ")
    speaker: Optional[str] = Field(None, description="ชื่อตัวละครที่กำลังพูด (ดึงจากคอลัมน์ Speaker หรือ Regex)")
    original_text: str = Field(..., description="ประโยคต้นฉบับที่ถูกกรองแท็กโค้ดออกแล้ว")
    
    current_state: TokenState = Field(default=TokenState.UNPROCESSED)
    retry_count: int = Field(default=0, description="จำนวนรอบที่วนใน Repair Loop")
    
    context: ContextData = Field(default_factory=ContextData)
    outputs: AgentOutputs = Field(default_factory=AgentOutputs)
    
    metadata: Dict[str, str] = Field(
        default_factory=dict, 
        description="เก็บข้อมูลโครงสร้างไฟล์ (เช่น แท็กคำสั่งภาพ หรือชื่อไฟล์) และ Role (ประเภทข้อความ) เพื่อใช้ตอนประกอบ Context และ Export กลับ"
    )

*(Historical Note: เดิม `speaker` ดึงจาก Regex เพียงอย่างเดียว และ `metadata` ใช้เก็บเฉพาะโค้ดไฟล์ ปัจจุบันอัปเดตให้ดึงข้อมูลจากโครงสร้าง CSV 8 คอลัมน์ที่รองรับ Role และ Speaker โดยตรง)*

```

## 5. Usage Example (ตัวอย่างการใช้งาน)

เมื่อโมดูล Parser อ่านไฟล์เกมเสร็จ จะสร้าง Object เริ่มต้นหน้าตาแบบนี้ส่งเข้า Event Bus:

```json
{
  "id": "scene1_line001",
  "speaker": "Aila",
  "original_text": "Is this... my true power?",
  "current_state": "PENDING",
  "retry_count": 0,
  "context": {
    "character_traits": [],
    "glossary_matches": {},
    "translation_memory": [],
    "story_summary": null
  },
  "outputs": {
    "translator_output": null,
    "editor_output": null,
    "qa_feedback": null,
    "timing_output": null,
    "final_output": null
  },
  "metadata": {
    "engine": "renpy",
    "original_code_line": "aila 'Is this... my true power?'"
  }
}

```
